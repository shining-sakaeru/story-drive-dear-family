## 최초 접수와 개발물 보완

release가 지연되면 작성·서명한 필수 DOCX와 승인 영상으로 먼저 접수할 수 있습니다. 이때 debug/unsigned APK를 선택 release 제출물로 기재하지 않습니다. 소스 링크를 참고로 넣는 경우 release APK 미제출 상태를 분명히 하고 개발 산출물 가산점 취득을 확정적으로 주장하지 않습니다.

마감 전 release 서명·설치·업로드가 끝나면 현재 Git 최종 커밋을 다시 확인하고, 같은 발신자로 전체 자료와 서명한 동의서를 포함한 수정 제출을 합니다. 서명 도우미 실행 성공은 실제 설치·실행·GitHub 업로드·이메일 접수 성공이 아닙니다.

현재 알려진 실차·확대/장시간 시험 한계는 기존 검증 보고서대로 유지합니다. 제출 준비를 이유로 미완료 native 태스크를 완료 처리하거나 기능을 추가하지 않습니다.
