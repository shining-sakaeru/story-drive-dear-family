# 30초 Auto-Tour 시연 대본

**기준**: 앱 투어 시작을 0초로 한다. 실제 영상은 부모가 Pleos 대상 기기에서 녹화하며, 이 문서는 녹화·청취·안전성을 검증했다는 뜻이 아니다. 화면 하단 또는 오버레이에 `실제 SDK 탑승 조회 · 센서/제어 Mock · 공용 스피커 또는 자막` 경계를 유지한다.

| 시간 | 화면·행동 | 내레이션/표시 문장 |
|---|---|---|
| 0–7초 | 2열 아이 소란 케어 | “아이 소란 상황입니다. 소음과 터널은 시연용 Mock이고, 이야기·공조·음장 출력도 Mock입니다.” |
| 7–14초 | 3열 부모님 피로 케어 | “부모님 휴식 제안입니다. 시간·체압·위치와 온열·요추·휴게소 출력은 모두 Mock입니다.” |
| 14–21초 | 조수석 Cozy 대화 | “조수석 대화 상태입니다. 음량 변화는 화면 시뮬레이션이며, 실제 독립 음장은 제공하지 않습니다.” |
| 21–30초 | 운전석 무음 리포트, 종료 | “운전석에는 무음 리포트를 보여 줍니다. 실제 SDK는 좌석 탑승 조회만 read-only로 확인하고, 차량 제어는 하지 않습니다. 현재 한국어 offline voice는 지원되지 않아 자막으로 시연합니다.” |

## 녹화자 체크 문구

- 시작 전 화면에 `정차 시연 · 센서/제어 MOCK`을 보인다.
- 실제 SDK 화면이 포함될 경우 `VEHICLE READ-ONLY` 영역만 실제 탑승 조회로 설명한다.
- 소음·수면·체압·위치·내비·공조·마사지·방향성 음장·소음 차폐는 실제 연동처럼 읽지 않는다.
- 음성이 들리지 않으면 성공으로 처리하지 말고 자막 시연으로 남긴다. 공용 스피커 출력을 좌석별 음장으로 설명하지 않는다.
- 녹화 후 부모가 영상의 실제 화면, 음성, 안전성을 직접 확인한다. 이 작업공간에서는 영상 완성·청취·안전성 검증을 주장하지 않는다.
